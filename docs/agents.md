# Agent Responsibilities

1. Emergency Incident Intake Agent - Collect, normalize, extract info
2. Situation Assessment & Severity Agent - Priority scoring, severity
3. Weather & Environmental Intelligence Agent - Weather data, forecasts
4. Geospatial & Accessibility Agent - Maps, routes, accessibility
5. Emergency Resource Management Agent - Track resources, availability
6. Resource Allocation & Response Planning Agent - Match, allocate, shortages
7. Emergency Coordination & Action Agent - Consolidate, plan, reports
8. Reviewer/Critic Agent (Optional) - Verify, detect contradictions
